What this is

Hplay is a click-wheel music player app. Its Get More screen fetches a single manifest.json file from a URL you set in Settings, and lists whatever apps and themes it finds — tap one and it downloads straight into the app. No app update or reinstall involved; add something here and it just shows up next time Get More is opened.

Making an app

An app is one self-contained .html file — its own inline CSS and JS (or CDN script tags if you want a library). When someone installs it, Hplay downloads that file and runs it inside a sandboxed <iframe>. That sandbox means:

  • No direct access to Hplay's library, settings, or storage — it's isolated from the host app except for the read-only bridge below.
  • Its own localStorage/cookies are unavailable too, so don't rely on saving state between opens — treat every open as a fresh session.
  • Network requests (e.g. fetch to an API you control) still work if you need one.
  • Design for a phone screen in portrait — touch input, no hover or right-click.

Test it by just opening your .html file directly in a browser before publishing — if it works there, it'll work in the sandbox.

Reading the library & stats

Apps can ask Hplay for a read-only snapshot of the song list and usage stats via postMessage — there's no write path, so this can't touch playback or change anything:

parent.postMessage({channel:'hplay', type:'getLibrary'}, '*');
parent.postMessage({channel:'hplay', type:'getStats'}, '*');

window.addEventListener('message', (e) => {
  if (!e.data || e.data.channel !== 'hplay') return;
  if (e.data.type === 'library') { /* e.data.data: [{title, artist, album}, ...] */ }
  if (e.data.type === 'stats')   { /* e.data.data: {opens, playCount, playMs,
    quizAnswered, quizCorrect, quizBest, songPlays, songCount} */ }
});

See the Library & Stats app under the Apps tab for a working example.

Making a theme

A theme is a small set of colors, no file needed — it lives directly in manifest.json:

{
  "id": "sunset", "name": "Sunset",
  "b": ["#hex1", "#hex2", "#hex3", "#hex4"],
  "w": ["#hex1", "#hex2", "#hex3", "#hex4"],
  "c": ["#hex1", "#hex2", "#hex3"]
}

b colors the body of the player (top to bottom), w/c color the click wheel. Optional lab/labsh set the wheel's label text and shadow color — leave them out and sensible defaults are used.

Publishing

Drop your app file in apps/, add an entry to manifest.json pointing at it (or a theme entry directly), then commit and push — or just edit the files on GitHub in the browser. Full schema reference is in the repo's README.md.
